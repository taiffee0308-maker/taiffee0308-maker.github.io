AutoClipper

YouTube 切り抜き動画の自動投稿ツール / Personal YouTube clip automation tool

概要 / Aboutプライバシーポリシー / Privacy Policy

概要 / About

AutoClipper は、運営者が管理する YouTube チャンネルに切り抜き動画をアップロードするための個人用ツールです。一般向けのサービスではなく、運営者本人のアカウントでのみ使用します。

AutoClipper is a personal tool used by its operator to upload clip videos to YouTube channels that the operator owns. It is not offered to the public and is used only with the operator's own Google accounts.

プライバシーポリシー / Privacy Policy

最終更新日 / Last updated: 2026-09-28

1. 取得する情報 / Data we access

Google の OAuth 認証を通じて、次の権限でのみ YouTube にアクセスします。

  • youtube.upload — 動画のアップロード / uploading videos
  • youtube.force-ssl — 動画情報・コメントの管理 / managing video metadata and comments
  • youtube.readonly — チャンネル・動画情報の取得 / reading channel and video information
  • yt-analytics.readonly — 再生数などの分析データの取得 / reading analytics

2. 利用目的 / How we use it

取得した情報は、運営者自身のチャンネルへの動画投稿と、その投稿内容の改善のためだけに使用します。

Data is used solely to publish videos to the operator's own channels and to improve those uploads.

3. 保存と共有 / Storage and sharing

認証トークンと取得したデータは運営者の端末内にのみ保存します。第三者への提供・販売・広告目的での利用は一切行いません。

OAuth tokens and retrieved data are stored only on the operator's own computer. We do not sell, share, or transfer this data to third parties, and do not use it for advertising.

AutoClipper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. AutoClipper uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

4. アクセスの取り消し / Revoking access

AutoClipper に与えたアクセス権は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。取り消し後、端末内に保存されたトークンは使用できなくなり、運営者が削除します。

You can revoke access at any time from your Google Account permissions page. Stored tokens then become unusable and are deleted by the operator.
